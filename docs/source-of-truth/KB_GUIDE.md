# KB 작성 가이드

## 1. 목적

KB(Knowledge Base)는 시민 답변의 근거가 되는 공식 행정 지식이다. 이번 MVP에서는 **4개 분야, 세부 주제 단위 20건**을 작성한다. 질문 예시를 많이 만드는 것보다 각 레코드가 공식 출처·확인일·승인 상태를 갖는 것이 우선이다.

## 2. 확정 범위

| 분야 | 수량 | 예시 |
| --- | --- | --- |
| 전입·주민등록 | 5건 | 전입신고 개요, 방문 준비물, 온라인 신청, 통보서비스, 법적 일반 원칙 |
| 증명서 발급 | 5건 | 등본/초본 차이, 등본 발급, 초본 발급, 열람, 무인발급기 |
| 대형폐기물 | 5건 | 배출 절차, 변경·환불, 침대 프레임, 매트리스, 배출요일·문의 |
| 지방세 일반 안내 | 5건 | 위택스 납부, 자동차세 경로, 납세증명, 세목별 과세증명, 납부확인서 |

## 3. KB 1건의 단위

KB 1건은 거대한 민원 전체 문서가 아니라 **하나의 명확한 안내 주제**다. 예를 들어 전입신고를 하나의 문서에 모두 넣지 않고 `기본 절차`, `방문 준비물`, `온라인 신청`, `통보서비스`처럼 나눈다. 이렇게 해야 검색 결과와 출처 범위를 추적하기 쉽다.

## 4. 필수 필드

| 필드 | 설명 | 검수 규칙 |
| --- | --- | --- |
| id | 고유 KB ID | 분야 접두어와 일련번호 사용 |
| category | 4개 지원 분야 중 하나 | 자유 입력 금지 |
| service_name | 세부 안내 주제 | 시민이 이해할 수 있는 이름 |
| question_examples | 대표 질문 3~5개 | 개인정보 없는 문장 |
| answer_summary | 근거 범위 안의 요약 | 출처에 없는 사실 추가 금지 |
| procedure_steps | 단계형 절차 | 순서가 있는 경우만 입력 |
| required_documents | 필요 서류 | 상황별 조건 분리 |
| processing_time | 처리 기간 | 기준일과 예외 표시 |
| fee | 수수료 | 규격·온라인/방문 차이 표시 |
| department | 담당 기관·부서 | 공식 기관 데이터와 연결 |
| source_title | 공식 출처명 | 필수 |
| source_url_or_id | URL 또는 문서 ID | 필수 |
| last_verified_at | 마지막 확인일 | 필수 |
| caution | 예외·한계 | 개인별 판단 금지 문구 포함 |
| status | DRAFT/PENDING/ACTIVE/REJECTED | ACTIVE만 시민 검색 |
| created_by/approved_by | 작성자·승인자 | 동일인 승인 차단 |

## 5. 작성 절차

1. `07_KB_출처대장.csv`에서 담당 행을 배정한다.
2. 공식 페이지를 열어 신청방법·서류·기간·수수료·기관을 확인한다.
3. 원문을 장문 복사하지 않고 필요한 사실을 구조화한다.
4. `last_verified_at`과 출처 URL을 기록한다.
5. 개인별 적용 여부나 법적 판단이 필요한 부분은 `caution`에 제한을 적는다.
6. 운영자가 DRAFT 후보를 작성한다.
7. 승인자가 출처 범위·최신성·개인정보·중복을 확인한다.
8. 승인된 레코드만 ACTIVE로 전환한다.

## 6. 출처 처리 원칙

- 출처명·URL·확인일은 LLM이 만들지 않는다.
- 서버가 검색된 KB 레코드의 메타데이터를 응답에 직접 결합한다.
- AI 생성 질문·초안은 시민 답변 근거로 사용할 수 없다.
- 수수료·처리기간처럼 변경 가능한 정보는 확인일을 항상 보여준다.
- 공식 페이지가 존재하지만 ACTIVE KB에 아직 등록되지 않은 경우에는 `공식 자료가 없다`고 말하지 않고 `현재 승인된 KB에 세부 근거가 등록되어 있지 않다`고 안내한다.

## 7. 승인 체크리스트

- [ ] 공식 출처인가
- [ ] 링크 또는 문서 ID가 유효한가
- [ ] 답변이 출처 범위를 벗어나지 않는가
- [ ] 개인정보가 없는가
- [ ] 담당 기관이 공식 데이터와 일치하는가
- [ ] 기존 KB와 중복되지 않는가
- [ ] 수수료·기간 등 변경 가능 정보의 기준일이 있는가
- [ ] 작성자와 승인자가 다른가

## 8. 회귀 시나리오용 예외

`KB-WASTE-03 침대 프레임 수수료`는 공식 출처대장에는 포함하되, 발표 전 개선 루프 시연을 위해 초기 ACTIVE 검색에서는 제외한다. 관리자가 공식 수수료 페이지를 근거로 후보를 작성하고 승인한 뒤 ACTIVE가 되면 동일 질문에 답변하도록 한다.
