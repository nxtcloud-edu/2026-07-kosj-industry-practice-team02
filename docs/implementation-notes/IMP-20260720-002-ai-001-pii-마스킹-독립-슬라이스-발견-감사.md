## 5. 설계 결정과 대안

### 추천

API 내부에 standard-library-only typed rule engine을 두고 명확한 PII는 category placeholder로
치환한다. 불확실한 PII가 남으면 masked text를 만들지 않고 provider·failure text 저장을 모두
차단한다.

### 대안

- Korean NER dependency: 정확도 잠재력은 있으나 dependency/모델/비용/결정성 때문에 보류.
- staging validator import: detection-only와 runtime masking의 책임이 달라 폐기.

이 추천은 아직 사용자 설계 승인을 받지 않았으므로 제품 코드나 TASK 상태를 변경하지 않았다.
