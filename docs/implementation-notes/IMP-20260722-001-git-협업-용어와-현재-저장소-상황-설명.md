## 11. 인간이 반드시 알아야 하거나 승인할 내용

- 이 프로젝트에서는 `main`에 직접 push하지 않고 작업 브랜치와 PR을 사용한다.
- Frontend 팀원 자가 병합은 허용 범위의 frontend-only green PR에만 해당한다.
- Codex Cloud는 branch와 Draft PR까지만 만들며 사람이 병합한다.
- 현재 PR #4는 GitHub상 CLEAN이지만 노트 ID 논리 충돌 때문에 아직 병합하면 안 된다.
- `reset --hard`, force-push, 공유 이력 재작성은 임의로 실행하지 않는다.
