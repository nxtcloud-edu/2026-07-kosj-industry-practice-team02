## 5. 설계 결정과 대안

### 선택

- package는 private ESM `@sejong-ai/shared-contracts@0.1.0`으로 두었다.
- `ajv@8.20.0`, `ajv-formats@3.0.1`, `yaml@2.9.0`만 dev dependency로 exact pin했다.
- OpenAPI의 모든 component schema를 `$defs`로 복제하고 내부 `#/components/schemas/*`만 rewrite한다.
- 알 수 없는 component와 외부 `$ref`는 즉시 실패시켜 부분 검증을 금지한다.
- fixture outcome뿐 아니라 keyword, instance path, missing/additional property 의미도 검사한다.

### 고려했지만 선택하지 않은 대안

- OpenAPI 전체 validator: 이번 fixture matrix보다 범위와 dependency가 커서 선택하지 않았다.
- schema를 손으로 축약 복사: 참조 누락과 drift를 숨길 수 있어 선택하지 않았다.
- `openapi-typescript`와 Pydantic 모델 동시 추가: CONTRACT-001B의 독립 RED/GREEN을 보존하기 위해 미뤘다.
- Office/source 전체 strictness 확장: 승인 범위를 넘어서는 계약 변경이라 미뤘다.
