## 5. 설계 결정과 대안

### 선택

1. 답변 원문과 해석을 `INTERVIEW_ANSWERS.md`에서 분리했다.
2. Q-LLM은 완전 해결로 과장하지 않고 “실제 사용 목표”만 부분확정했다.
3. 관리형 배포 추천과 초기 local-first 0원 목표를 분리했다.
4. 관리자 demo header는 local/private 역할 시연으로만 제한하고 public route-off를 ADR/API에 기록했다.
5. retention은 `failed_questions` DELETE가 아니라 `masked_question` NULL+`text_purged_at`, metadata/FK 유지로 고정했다.
6. OUT_OF_SCOPE 시민 폴백 enum과 저장 가능한 failure enum을 분리했다.
7. 남은 blocker를 포함한 계획은 `Interviewing`으로 두고 제품 구현을 시작하지 않았다.

### 이유

- 사용자의 명시 답변, AGENTS 인간/AI 경계, privacy/approval source-of-truth를 동시에 만족한다.
- 실패 행 hard delete는 후보 FK·감사 연결을 깨지만 텍스트 NULL 파기는 보관 최소화와 운영 연결을 함께 만족한다.
- actual provider와 0원은 공급자/하드웨어 증거 없이 양립을 가정할 수 없다.

### 고려했지만 선택하지 않은 대안

- 즉시 `git init`/pnpm/uv 설치: 최종 계획 승인 전 실행 금지라 제외.
- Q-LLM B를 특정 vendor/model 승인으로 해석: 답변에 공급자·비용·데이터 조건이 없어 제외.
- 만료 시 failed row hard delete: Q-PRIV A와 후보 FK 유지에 반해 제외.
- public demo header를 인증으로 사용: 위조 가능해 제외.
- PM/Frontend도 공식 KB 작성 유지: 명시 답변과 충돌해 제외.
- 모든 알려진 OpenAPI/DB gap을 이번에 일괄 수정: Q-PRIV/Q-SEC 직접 영향만 최소 변경하고 나머지는 계획/CONTRACT-001로 이관.

- 계약상 실패 질문 텍스트 수명만 다음으로 바뀌었다.

```text
created_at
→ masked_question retained, text_purged_at=NULL
→ text_expires_at = created_at + 30 days
→ idempotent UPDATE sets masked_question=NULL, text_purged_at=actual time
→ failure metadata/status and kb_candidate FK remain
```

- OUT_OF_SCOPE는 시민 `FallbackReason`에는 남지만 `StoredFailureReason`/DB failed row에서는 금지된다.

- verified date: 기존 source registry 값은 변경하지 않았다. PM 전수 승인 전 공식 ACTIVE로 간주하지 않는다.

## 11. 인간이 반드시 알아야 하거나 승인할 내용

1. 실제 LLM을 쓰겠다는 목표와 초기 외부 예산 0원이 충돌한다. Q-LLM-002에서 hosted budget 또는 local hardware/runtime을 선택해야 한다.
2. hosted provider를 택하면 합성 local/private 입력 허용과 보관/ZDR 조건을 Q-LLM-003에서 승인해야 한다.
3. Q-DB-001의 migration tool은 schema/rollback/RLS와 새 의존성을 바꾸므로 인간 결정이 필요하다.
4. 이름·상세주소 오탐/누락 기준, chat session, SYSTEM_ERROR HTTP 계약은 구현 전 답이 필요하다.
5. private Git 원격/CI는 B/High이며 계정·quota·소유자 승인이 필요하다.
6. 현재 계획은 Interviewing이다. 사용자가 `진행`/`구현 시작`을 명시하기 전 Git init·설치·제품 코드를 시작하지 않는다.
7. OpenAPI/DB 0.2는 실행물이 아니라 승인된 논리 draft다.

## 12. AI 내부 구현 세부 — 필요할 때만 보면 되는 내용
