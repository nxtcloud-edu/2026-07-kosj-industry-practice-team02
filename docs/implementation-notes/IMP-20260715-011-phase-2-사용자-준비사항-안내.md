### 이유

### 고려했지만 선택하지 않은 대안

- 키를 채팅으로 받기: 비밀 노출 위험 때문에 금지했다.
- KB 20건 직접 작성 요청: D-011의 AI/Data·Backend 작성 책임과 충돌한다.
- 원격 Git·CI·공개 배포 준비: 현재 범위 밖이다.
