# 03. 입찰 제안서 — AI 기반 시민 민원 통합 응대 플랫폼 구축

## 제안 개요

| 항목 | 내용 |
|---|---|
| 제안명 | 세종 민원 AI 길잡이 구축 제안 |
| 제안 방향 | 시민용 민원 AI 플랫폼 + 관리자용 AI 민원 운영센터 |
| 핵심 가치 | 24시간 민원 안내, 출처 기반 신뢰 답변, 답변 실패 질문 기반 지식베이스 개선 |
| 차별점 | 단순 챗봇이 아니라 민원 데이터를 분석해 행정 정보 품질을 지속 개선하는 운영형 플랫폼 |

## 1. 사업 이해

본 사업은 시민이 일상 언어로 전입, 세금, 복지, 인허가, 증명서, 대형폐기물 등 생활 민원을 질문하면 AI가 24시간 정확한 안내를 제공하고, 필요 서류·절차·담당 부서까지 연결하여 행정 효율과 시민 접근성을 높이는 것을 목적으로 한다.

RFP는 자연어 질의응답, 민원 의도 분류, 절차·서류 안내, 기관·담당 연결, 후속질문, 폴백 처리를 핵심 기능으로 제시하고 있으며, 행정 지식베이스와 기관 정보, 비식별 대화 로그를 활용한 품질 개선도 요구한다. 또한 모든 답변은 행정 정보에 근거해야 하며, 근거가 부족한 경우 폴백해야 한다.

본 팀은 이러한 요구를 충족하는 데서 나아가, AI가 답변하지 못한 질문을 관리자 대시보드에서 분석하고 지식베이스 개선 후보로 전환하는 **AI 민원 운영센터**를 추가 제안한다.

## 2. 문제 정의

### 2.1 시민 측면 문제

1. 민원 정보가 여러 사이트와 부서에 흩어져 있어 원하는 정보를 찾기 어렵다.
2. 전입신고, 증명서 발급, 대형폐기물 신고처럼 반복되는 생활 민원도 절차·서류·담당 기관을 매번 확인해야 한다.
3. 평일 근무시간 외에는 전화나 방문 상담이 어렵다.
4. 행정 용어가 어렵고, 개인 상황에 따라 어느 부서에 문의해야 하는지 판단하기 어렵다.

### 2.2 행정기관 측면 문제

1. 단순·반복 문의가 민원 담당자의 시간을 많이 차지한다.
2. 부서와 창구마다 안내 기준이 달라질 수 있다.
3. 시민들이 실제로 어떤 질문을 많이 하는지, 어떤 질문에서 답변이 실패하는지 체계적으로 파악하기 어렵다.
4. 지식베이스를 개선해야 할 우선순위를 데이터 기반으로 정하기 어렵다.

### 2.3 핵심 문제 문장

> 현재 민원 응대는 시민에게는 접근성과 정확성의 문제를, 행정기관에게는 반복 응대와 지식 관리의 문제를 동시에 발생시키고 있다.

## 3. 해결 방안

### 3.1 제안 솔루션

**세종 민원 AI 길잡이**는 시민용 AI 챗봇과 관리자용 AI 민원 운영센터로 구성된다.

```text
시민 질문
→ 민원 의도 분류
→ 행정 지식베이스 검색
→ 출처 기반 답변
→ 필요 시 후속질문/폴백
→ 비식별 로그 저장
→ 관리자 대시보드 분석
→ 지식베이스 개선
```

### 3.2 시민용 민원 AI 플랫폼

| 기능 | 설명 |
|---|---|
| 자연어 민원 질문 | 시민이 일상 언어로 질문 가능 |
| 민원 의도 분류 | 전입, 세금, 복지, 인허가 등으로 자동 분류 |
| 절차·서류 안내 | 필요 서류, 신청 방법, 처리 기간, 수수료 안내 |
| 출처 기반 답변 | 답변에 근거 문서와 최신 확인일 표시 |
| 후속질문 | 질문이 모호하면 선택지로 조건 좁힘 |
| 폴백 처리 | 근거 부족·개인별 조회성 질문은 담당 부서 연결 |
| 기관 연결 | 주민센터/부서/연락처/지도 안내 |
| 모바일 우선 | 스마트폰 기준 UI 설계 |

### 3.3 관리자용 AI 민원 운영센터

| 기능 | 설명 |
|---|---|
| 운영 현황 Overview | 총 질문 수, 자동 답변 성공률, 폴백 비율, 평균 응답시간 표시 |
| 답변 실패 질문 관리 | AI가 답하지 못한 질문과 실패 원인 관리 |
| 민원 자동 분석 | 유형별·시간대별·지역별·부서별 민원 분석 |
| 지식베이스 개선 추천 | 반복 실패 질문을 FAQ/출처/부서 매핑 개선 후보로 제안 |
| 품질 리포트 | 테스트 질문 정확도, 출처 표기율, 폴백 적절성, 마스킹 성공률 점검 |
| 주간 인사이트 리포트 | 주요 민원 변화와 개선 과제를 자동 요약 |

### 3.4 핵심 차별점

일반 민원 챗봇은 답변 후 종료된다. 본 서비스는 답변 실패 질문을 비식별 로그로 분석하여 지식베이스 개선 후보로 전환한다. 즉, 시간이 지날수록 자동 응대 품질이 향상되는 **민원 개선 루프**를 제공한다.

| 구분 | 일반 민원 챗봇 | 세종 민원 AI 길잡이 |
|---|---|---|
| 운영 방식 | 질문에 답변 후 종료 | 실패 질문을 분석해 개선 |
| 관리자 기능 | 단순 로그 조회 | 민원 자동 분석 대시보드 |
| 답변 실패 처리 | 담당 부서 안내 | 실패 원인 분석 + FAQ 후보 생성 |
| 데이터 활용 | 제한적 | 유형·시간대·지역·부서별 분석 |
| 품질 개선 | 수동 개선 | 지식베이스 개선 후보 자동 추천 |
| 최종 가치 | 민원 응대 자동화 | 행정 정보 품질 개선까지 연결 |

## 4. 시장 및 수요 분석

### 4.1 목표 시장

본 서비스의 1차 목표 시장은 세종시와 같은 지방자치단체의 민원 응대 영역이다. 장기적으로는 광역·기초 지자체, 공공기관, 공기업, 대학 행정, 복지기관 등 반복 민원과 행정 안내 수요가 많은 조직으로 확장할 수 있다.

### 4.2 고객군

| 고객군 | 니즈 |
|---|---|
| 지방자치단체 | 반복 민원 자동화, 24시간 응대, 민원 통계 분석 |
| 공공기관 | 행정 정보 검색, 민원 처리 경로 안내, 상담 품질 관리 |
| 대학/교육기관 | 학사·장학·행정 민원 자동응대 |
| 복지기관 | 복지제도 안내, 상담 전 사전 분류 |
| 공기업 | 고객 문의 자동화, 지식베이스 운영 |

### 4.3 정책·환경 적합성

공공 행정 서비스는 검색 중심에서 대화형·AI 기반 안내로 변화하고 있다. 행정안전부는 정부24+에 AI 기능을 확대하여 국민이 일상 언어로 정부 서비스를 찾을 수 있도록 대국민 시범서비스를 시작했다고 발표했다. 또한 AI 통합민원플랫폼은 국민이 여러 기관을 찾아다니지 않고 한 곳에서 민원을 해결하도록 민원 내용을 분석하고 처리 방법을 안내하는 방향으로 제시되고 있다.

이러한 정책 흐름은 본 서비스의 방향인 자연어 민원 안내, 담당 시스템 연결, 처리 상태 안내, 행정 지식베이스 기반 답변과 부합한다.

### 4.4 시장 기회

1. 지방자치단체마다 반복 민원과 야간 응대 공백 문제가 존재한다.
2. 생성형 AI 도입이 확산되면서 공공기관도 근거 기반·보안 중심 AI 서비스 수요가 증가하고 있다.
3. 단순 챗봇보다 관리자 분석과 지식베이스 개선 기능을 결합한 운영형 플랫폼의 차별성이 크다.
4. 한 지자체에서 검증된 지식베이스·대시보드 구조는 다른 지자체로 확장 가능하다.

## 7. 기술 구성

### 7.1 시스템 아키텍처

```text
Frontend
- 시민용 웹: 챗봇, 민원 카드, 기관 찾기
- 관리자 웹: KPI, 실패 질문, 자동 분석, KB 추천

Backend
- 질문 처리 API
- 민원 의도 분류
- 지식베이스 검색
- 답변 생성/폴백
- 로그 저장
- 관리자 분석 API

Data
- 행정 지식베이스
- 기관/부서 정보
- 비식별 대화 로그
- 실패 질문
- 테스트 질문/평가 결과

AI Layer
- 개인정보 마스킹
- 의도 분류
- RAG 검색
- 출처 검증
- 실패 원인 분석
- 개선 후보 추천
```

### 7.2 보안·품질 설계

| 항목 | 대응 방안 |
|---|---|
| 개인정보 최소수집 | 이름, 주민번호, 연락처 입력 요구 금지 |
| 비식별 로그 | 질문 저장 전 개인정보 마스킹 |
| 환각 방지 | 출처 없는 답변 생성 금지 |
| 폴백 | 신뢰도 낮음, 개인별 조회, 최신 정보 부족 시 담당 부서 연결 |
| 접근성 | 쉬운 말, 큰 글씨, 고대비, 모바일 우선 |
| 정확성 점검 | 테스트 질문 100개 기반 품질 리포트 |

## 13. 결론

본 제안은 RFP의 기본 요구사항을 충족하는 것에 그치지 않고, 답변 실패 질문을 행정 지식베이스 개선 후보로 전환하는 관리자용 AI 민원 운영센터를 함께 제공한다. 이를 통해 세종 민원 AI 길잡이는 단순 민원 챗봇이 아니라, 시민 편의와 행정 품질을 함께 향상시키는 운영형 공공 AI 플랫폼으로 발전할 수 있다.

> 세종 민원 AI 길잡이는 시민에게 답변하는 챗봇에서 끝나지 않고, 답변 실패 질문과 민원 로그를 분석해 행정 지식베이스를 지속적으로 개선하는 공공 AI 민원 운영 플랫폼이다.
