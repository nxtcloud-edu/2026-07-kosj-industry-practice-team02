# 세종 민원 AI 길잡이 — 개발/제안 통합 패키지

본 패키지는 RFP 「AI 기반 시민 민원 통합 응대 플랫폼 구축」을 바탕으로, 최종 개발 방향을 **시민용 민원 AI 플랫폼 + 관리자용 AI 민원 운영센터**로 확정한 뒤 실제 개발과 입찰 제안서 작성에 바로 사용할 수 있도록 구성한 자료입니다.

## 최종 제품 정의

> 시민은 민원을 쉽게 해결하고, 관리자는 시민 질문 데이터를 분석하여 행정 지식베이스를 지속적으로 개선하는 운영형 공공 AI 플랫폼

## 핵심 차별점

단순 챗봇은 시민 질문에 답변하고 종료됩니다. 본 서비스는 답변하지 못한 질문과 폴백 사례를 비식별 로그로 축적하고, 관리자 대시보드에서 실패 원인·민원 유형·시간대·담당 부서·개선 우선순위를 분석하여 지식베이스 개선 후보로 전환합니다.

```text
시민 질문 → AI 답변/폴백 → 비식별 로그 저장 → 실패 질문 분석 → KB 개선 후보 → 관리자 보완 → 자동응대 품질 향상
```

## 주요 파일

| 파일 | 용도 |
|---|---|

| `02_개발용_가이드.md` | 개발자가 바로 구현할 수 있는 기술/DB/API/일정 가이드 |
| `03_입찰제안서.md` | 문제-해결-시장-수익모델-실행계획-MVP-로드맵 포함 제안서 |
| `docs/04_관리자_대시보드_상세설계.md` | 차별화 기능인 관리자 대시보드 상세 설계 |
| `docs/05_AI_RAG_품질_보안_설계.md` | 근거 기반 답변, 폴백, 개인정보 마스킹, 품질평가 설계 |

| `data/*.csv` | 지식베이스, 기관, 테스트 질문, mock 로그 샘플 |
| `backend/` | FastAPI 기반 백엔드 스타터 코드 |
| `frontend/static-prototype/` | 시민용/관리자용 정적 화면 프로토타입 |

## 빠른 실행 방향

1. `db/schema.sql`로 DB 구조를 확정합니다.
2. `data/kb_seed.csv`, `data/offices_seed.csv`를 기반으로 시드 데이터를 넣습니다.
3. `backend/app/main.py`의 mock API를 실제 DB 연동 API로 확장합니다.
4. 프론트엔드는 시민용 `/chat`, 관리자용 `/admin` 화면을 분리합니다.
5. 발표 전에는 `data/test_questions_100.csv`로 품질 리포트를 생성합니다.

## 발표 핵심 메시지

> 저희 서비스는 시민 질문에 답변하는 것에서 끝나지 않습니다. AI가 답하지 못한 질문을 분석해 지식베이스 개선 후보로 전환하고, 민원 유형·시간대·지역·담당 부서별 분석을 통해 행정 응대 품질을 지속적으로 개선하는 AI 민원 운영센터를 제공합니다.
