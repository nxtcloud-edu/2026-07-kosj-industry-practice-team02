# 05. AI/RAG/품질/보안 설계서

## 1. AI 설계 원칙

1. 답변은 행정 지식베이스에 근거해야 한다.
2. 출처가 없는 답변은 생성하지 않는다.
3. 신뢰도가 낮으면 담당 부서 연결로 폴백한다.
4. 개인정보는 저장하지 않고 마스킹한다.
5. 복지·세금·인허가의 최종 판단은 AI가 단정하지 않는다.
6. 관리자 대시보드는 실패 질문을 분석해 KB 개선 후보를 제공한다.

## 2. RAG 파이프라인

```text
질문 입력
→ 개인정보 마스킹
→ 안전성 검사
→ 민원 의도 분류
→ KB 검색
→ 검색 결과 재정렬
→ 근거 기반 답변 생성
→ 출처 검증
→ 정상 답변/후속질문/폴백 결정
→ 비식별 로그 저장
```

## 3. 개인정보 마스킹 규칙

| 유형 | 예시 | 저장 형태 |
|---|---|---|
| 주민등록번호 | 900101-1234567 | [주민등록번호] |
| 전화번호 | 010-1234-5678 | [전화번호] |
| 이메일 | user@test.com | [이메일] |

| 접수번호 | SJ-2026-0012 | mock 조회 외 로그는 [접수번호] |

## 4. 폴백 정책

### 4.1 폴백 메시지 표준

```text
이 질문은 AI가 근거 없이 답변하면 부정확할 수 있습니다.
현재 확인된 행정 지식베이스만으로는 정확한 답변을 제공하기 어렵기 때문에 담당 부서 안내로 연결합니다.
```

### 4.2 폴백 유형별 처리

| 유형 | 예시 | 처리 |
|---|---|---|
| KB 없음 | 반려동물 등록 어디서 해요? | 담당 부서 연결 + KB 후보 저장 |
| 최신 정보 필요 | 청년 월세 신청 기간 언제예요? | 최신 공고 확인 안내 |
| 개인별 조회 | 내 자동차세 체납액 알려줘 | 공식 시스템/부서 연결 |
| 개인정보 포함 | 주민번호 입력 | 마스킹 + 저장 금지 안내 |
| 질문 모호 | 신고하려고요 | 후속질문 제공 |

## 5. 품질평가 지표

| 지표 | 정의 |
|---|---|
| 정확 답변률 | 테스트 질문 중 기대 답변과 일치한 비율 |
| 출처 표기율 | 정상 답변 중 출처가 포함된 비율 |
| 폴백 적절성 | 답변 불가 질문을 안전하게 폴백한 비율 |
| 응답시간 | 질문 입력부터 응답까지 평균 시간 |
| 마스킹 성공률 | 개인정보 패턴을 마스킹한 비율 |

## 6. 관리자 분석용 AI

관리자 기능에는 다음 AI/분석 기능을 사용한다.

1. 실패 질문 원인 분류
2. 유사 실패 질문 그룹화
3. 키워드 추출
4. 지식베이스 개선 후보 추천
5. 주간 리포트 요약 생성

초기 구현은 규칙/키워드 기반으로 시작하고, 고도화 단계에서 embedding clustering과 LLM 요약을 적용한다.
