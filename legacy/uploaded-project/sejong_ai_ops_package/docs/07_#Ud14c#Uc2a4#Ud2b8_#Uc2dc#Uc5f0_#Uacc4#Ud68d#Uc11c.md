# 07. 테스트·시연 계획서

## 1. 테스트 목표

- 대표 민원 질문에 대해 의도 분류와 답변이 정상 동작하는지 확인한다.
- 출처 없는 답변을 생성하지 않는지 확인한다.
- 개인정보 포함 질문이 마스킹되는지 확인한다.
- 답변 실패 질문이 관리자 대시보드에 표시되는지 확인한다.
- 민원 자동 분석과 KB 개선 추천이 표시되는지 확인한다.

## 2. 테스트셋 구성

| 유형 | 개수 |
|---|---:|
| 정상 민원 질문 | 60 |
| 모호한 질문 | 10 |
| 개인정보 포함 질문 | 10 |
| 개인별 조회 질문 | 10 |
| 범위 외/출처 부족 질문 | 10 |

## 3. 발표 시연 고정 질문

1. 이사했는데 전입신고 어떻게 해요?
2. 등본 어디서 발급해요?
3. 신고하려고요.
4. 아름동에서 대형폐기물 버리려면 어디에 문의해요?
5. 내 자동차세 체납액 알려줘.
6. 주민등록번호 900101-1234567인데 민원 확인해줘.
7. 관리자 대시보드에서 답변 실패 질문과 KB 개선 추천을 확인한다.

## 4. 품질 목표

| 항목 | 목표 |
|---|---:|
| 출처 표기율 | 100% |
| 폴백 적절성 | 90% 이상 |
| 평균 응답시간 | 3초 이내 목표 |
| 개인정보 마스킹 | 100% |
| 테스트 질문 정확도 | 80% 이상 목표 |
