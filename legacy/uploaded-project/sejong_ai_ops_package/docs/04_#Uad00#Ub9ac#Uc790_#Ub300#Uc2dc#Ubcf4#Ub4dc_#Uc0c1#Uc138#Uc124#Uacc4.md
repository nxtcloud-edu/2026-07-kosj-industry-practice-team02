# 04. 관리자 대시보드 상세 설계 — AI 민원 운영센터

## 1. 목적

관리자 대시보드는 본 프로젝트의 핵심 차별화 기능이다. 시민용 챗봇이 답변을 제공하는 데서 끝나는 것이 아니라, 답변 실패 질문과 민원 로그를 분석하여 행정 지식베이스 개선 후보를 생성하고, 민원 운영 품질을 지속적으로 개선하는 역할을 한다.

## 2. 메뉴 구조

```text
AI 민원 운영센터
├─ Overview
├─ 답변 실패 질문
├─ 민원 자동 분석
├─ 지식베이스 개선 추천
├─ 답변 품질 리포트
├─ 담당 부서 연결 현황
└─ 주간 인사이트 리포트
```

## 3. Overview

### 3.1 KPI 카드

| KPI | 계산 기준 | 예시 |
|---|---|---:|
| 총 질문 수 | user message count | 328 |
| 자동 답변 성공률 | answered / total | 84% |
| 폴백 비율 | fallback / total | 16% |
| 평균 응답시간 | avg response_time_ms | 1.7초 |
| 출처 표기율 | source_count > 0 / answered | 100% |
| 개인정보 감지 | pii_flags count | 8 |
| 신규 KB 후보 | open recommendations | 12 |

### 3.2 화면 구성

- 상단: KPI 카드 7개
- 중단 왼쪽: 민원 유형별 비율 차트
- 중단 오른쪽: 최근 급증 민원 알림
- 하단 왼쪽: 최근 답변 실패 질문
- 하단 오른쪽: 개선 우선순위 TOP 5

## 4. 답변 실패 질문 관리

### 4.1 저장 기준

다음 조건에서 실패 질문으로 저장한다.

- 출처 문서가 없음
- 검색 결과 신뢰도가 낮음
- 질문이 모호하여 후속질문으로도 해결되지 않음
- 개인별 정보 조회가 필요함
- 최신 공고/기간 정보가 필요함
- 담당 부서 매핑이 없음

### 4.2 테이블 컬럼

| 컬럼 | 설명 |
|---|---|
| question_masked | 마스킹된 질문 |
| estimated_intent | 추정 민원 유형 |
| failure_reason | 실패 원인 |
| recommended_action | 추천 조치 |
| related_count | 유사 질문 수 |
| priority | 우선순위 |
| status | 신규/검토중/처리완료/보류 |
| assigned_admin | 담당 관리자 |
| created_at | 최초 발생일 |

### 4.3 실패 원인 태그

| 태그 | 의미 |
|---|---|
| KB_MISSING | 지식베이스 없음 |
| SOURCE_INSUFFICIENT | 출처 부족 |
| QUESTION_AMBIGUOUS | 질문 모호 |
| PRIVATE_LOOKUP | 개인별 조회 필요 |
| DEPARTMENT_UNKNOWN | 담당 부서 불명확 |
| NEEDS_LATEST_INFO | 최신 정보 필요 |

## 5. 민원 자동 분석

### 5.1 분석 항목

- 민원 유형별 질문 수
- 시간대별 문의 분포
- 지역/동별 문의 분포
- 폴백 사유별 분포
- 담당 부서 연결 건수
- 민원 유형별 자동답변 성공률
- 주요 키워드
- 급증 민원 알림

### 5.2 급증 민원 탐지 기준

```text
증가율 = (이번 기간 질문 수 - 이전 기간 질문 수) / 이전 기간 질문 수
```

알림 조건:

- 질문 수 5건 이상
- 전주 대비 30% 이상 증가
- 또는 최근 3일간 동일 키워드 10건 이상 발생

## 6. 지식베이스 개선 추천

### 6.1 추천 후보 생성 방식

1. 실패 질문 수집
2. 유사 질문 그룹화
3. 민원 유형 추정
4. 실패 원인 분석
5. 관련 담당 부서 추정
6. 개선 우선순위 계산
7. 관리자에게 추천 카드 표시

### 6.2 우선순위 산식

```text
Priority = FrequencyScore × 0.4 + FailureRateScore × 0.3 + GrowthScore × 0.2 + ImportanceScore × 0.1
```

### 6.3 추천 카드 예시

```text
대형폐기물 품목별 수수료 보완 필요
- 관련 실패 질문: 21건
- 자동 답변 성공률: 68%
- 주요 키워드: 침대, 소파, 스티커, 수수료
- 추천 조치: 품목별 수수료 FAQ 추가
- 우선순위: 92 / 높음
```

## 7. 품질 리포트

### 7.1 평가 항목

| 항목 | 목표 |
|---|---:|
| 테스트 질문 수 | 100개 이상 |
| 정확 답변률 | 80% 이상 목표 |
| 출처 표기율 | 100% |
| 폴백 적절성 | 90% 이상 목표 |
| 개인정보 마스킹 성공률 | 100% |
| 평균 응답시간 | 3초 이내 목표 |

### 7.2 민원 유형별 결과

- 전입신고
- 증명서 발급
- 대형폐기물
- 지방세
- 복지
- 인허가
- 교통/주차
- 생활/환경

## 8. 주간 인사이트 리포트

### 8.1 자동 생성 문장 예시

```text
이번 주 총 328건의 민원 질문이 접수되었으며, 자동 답변 성공률은 84%였습니다.
가장 많이 접수된 민원은 전입/주민등록 분야로 전체의 31%를 차지했습니다.
대형폐기물 관련 질문은 전주 대비 42% 증가했으며, 품목별 수수료 안내 데이터 보완이 필요한 것으로 분석되었습니다.
답변 실패 질문 중 12건은 반려동물 등록 관련 문의로 묶였고, 현재 지식베이스에 해당 항목이 없어 FAQ 추가가 권장됩니다.
```

### 8.2 구현 방식

초기 버전은 통계값을 기반으로 템플릿 문장을 생성한다. 시간이 남으면 LLM을 활용해 자연스러운 요약문을 생성하되, 수치와 원인은 시스템 집계값만 사용하도록 제한한다.
