## 1. 프로젝트 소개

세종 민원 AI 길잡이는 시민이 일상어로 민원을 질문하면 행정 지식베이스에 근거해 절차, 서류, 담당 부서를 안내하고, 답변 실패 질문을 관리자 대시보드에서 분석해 지식베이스를 지속적으로 개선하는 **운영형 공공 AI 플랫폼**이다.

우리 팀의 차별점은 "시민에게 답변하는 챗봇"에서 끝나지 않는다는 점이다. AI가 답변하지 못한 질문을 수집하고 분석하여 행정 지식베이스 개선 후보로 전환하는 **관리자용 AI 민원 운영센터**를 함께 제안한다.

> 팀 내부 기준 문장: **"모르면 지어내지 않고, 알면 끝까지 안내한다."**

```text
세종 민원 AI 길잡이
├─ 1. 시민용 민원 AI 플랫폼
│  ├─ 자연어 민원 질문 및 민원 유형 분류
│  ├─ 절차, 서류, 수수료, 처리 기간 안내
│  ├─ 출처 기반 답변 및 후속질문
│  ├─ 폴백 및 담당 부서 연결
│  └─ 모바일 우선 UI
│
└─ 2. 관리자용 AI 민원 운영센터
   ├─ 답변 실패 질문 관리
   ├─ 민원 자동 분석 (유형별, 시간대별, 지역별)
   ├─ 지식베이스 개선 추천
   └─ 답변 품질 리포트
```

## 2. 해결하려는 문제

현재 시민 민원 안내는 전화, 방문, 여러 행정 사이트에 분산되어 있어 시민이 필요한 절차와 서류를 빠르게 확인하기 어렵다.

| 문제 영역 | 현황 | 우리 팀의 해결 방향 |
|---|---|---|
| 행정 효율 | 단순 반복 문의에 인력이 소모됨 | 반복 민원을 AI 자동응대로 분리 |
| 시민 접근성 | 야간, 주말, 휴일에는 즉시 안내받기 어려움 | 24시간 자연어 응대 채널 제공 |
| 정보 정확성 | 부서와 창구마다 안내 기준이 다를 수 있음 | 행정 지식베이스 기반의 일관된 출처 표기 답변 |
| 운영 개선 | 어떤 행정 정보가 부족한지 알기 어려움 | 답변 실패 질문 분석으로 지식베이스 지속 개선 |

## 3. 주요 기능

### 시민용 민원 AI 플랫폼

- **자연어 질의응답**: 시민 질문을 이해하고 FAQ, 조례, 업무 매뉴얼 등 행정 지식베이스에 근거해 답변한다. 모든 답변에 출처 카드를 표기한다. (SFR-001, SER-003, COR-001)
- **민원 의도 분류**: 전입, 증명서, 대형폐기물, 지방세, 복지 등 10개 대표 민원 카테고리로 자동 분류한다. (SFR-002)
- **절차와 서류 카드 안내**: 필요 서류, 신청 방법, 처리 기간, 수수료를 카드 형태로 단계별 안내한다. (SFR-003)
- **기관 안내**: 동 선택 기반으로 가까운 주민센터, 담당 부서, 연락처를 안내한다. (SFR-004)
- **후속질문**: 질문이 모호하면 추측하지 않고 선택형 후속질문으로 조건을 좁힌다. (SFR-005)
- **폴백 처리**: 근거가 부족하거나 개인별 조회가 필요한 질문은 담당 부서 연결로 안전하게 넘긴다. (SFR-006)
- **개인정보 보호**: 개인정보 입력을 감지해 마스킹하고 비식별 로그만 저장한다. (SER-001, SER-002, DAR-003)
- **모바일 우선 반응형 UI 및 접근성 모드**: 쉬운 말, 큰 글씨, 고대비를 지원한다. (COR-002, QUR-001)

### 관리자용 AI 민원 운영센터

- **운영 KPI Overview**: 총 질문 수, 자동 답변 성공률, 폴백률, 평균 응답시간, 출처 표기율을 한눈에 확인한다.
- **답변 실패 질문 관리**: AI가 답하지 못한 질문을 실패 원인별로 분류하고 개선 대상으로 전환한다.
- **민원 자동 분석**: 유형별, 시간대별, 지역별 문의 통계와 급증 민원을 탐지한다.
- **지식베이스 개선 추천**: 반복 실패 질문을 묶어 FAQ 추가 후보를 우선순위와 함께 제안한다.
- **답변 품질 리포트**: 테스트 질문 100개 기준으로 의도 분류 정확도, 출처 표기율, 폴백 적절성을 수치화한다. (QUR-002)

## 5. 실행 방법

> ⚠️ MVP 개발 진행에 따라 업데이트 예정이다.

```bash
# 1. 저장소 클론
git clone https://github.com/nxtcloud-edu/2026-07-kosj-industry-practice-team02.git
cd 2026-07-kosj-industry-practice-team02

# 2. Backend 실행
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
# API 서버: http://localhost:8000

# 3. Frontend 실행
cd frontend
npm install
npm run dev
# 웹 앱: http://localhost:3000
```

환경 변수는 `backend/.env.example`과 `frontend/.env.example`을 참고해 설정한다. API 키 등 비밀 값은 커밋하지 않는다.
